# Epstein Public-Record Investigation Desk

## Exact purpose

**Real-time investigative journalism console** for the Jeffrey Epstein case using **only public records**: DOJ disclosures, court filings, FOIA, and reputable wire/timeline sources. Powered by the **MA-OS-12** 12-agent swarm (collect → normalize → distill → classify → ontology → verify with SOLID/MAYBE tags).

It is **not** a conspiracy engine. Association ≠ guilt. No CSAM. HITL on sensitive victim identities.
