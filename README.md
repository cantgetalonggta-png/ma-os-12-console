# MA-OS-12 Console

Web control panel for the 12-agent Multi-Agent Operating System.

## Run

```bash
npm install
npm run dev   # 0.0.0.0:8080
npm run build
python3 yolo_orchestrator.py --yolo
```

## Swarm backend (optional)

```bash
python3 artifacts/swarm_os/verify_deploy.py
```
